```php
Route::get('/posts/{post}', function (Post $post) {
    return view('posts.show', ['post' => $post]);
});
```

`/posts/hello-world` loads `content/posts/hello-world.md`, and a missing file gives a 404.

[Global scopes](/docs/querying#global-scopes) apply here too, so a record they filter out also
gives a 404.

## Binding on another field

Name a frontmatter field to resolve on that instead:

```php
Route::get('/blog/{post:permalink}', function (Post $post) {
    // ...
});
```

Or set it once on the model:

```php
class Post extends Model
{
    use Paper;

    public function getRouteKeyName(): string
    {
        return 'permalink';
    }
}
```

## Scoped bindings

A child route parameter can be scoped to its parent through a [relationship](/docs/relationships):

```php
Route::get('/authors/{author}/posts/{post}', function (Author $author, Post $post) {
    // ...
})->scopeBindings();
```

A post that belongs to another author gives a 404.

The post is looked up through `Author::posts()`, which has to use `hasManyPaper`.
